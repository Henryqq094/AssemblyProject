# 期中實作：成員資料輸入與加總

使用 ARM 組合語言，透過 C 標準函式庫的 `printf` 與 `scanf` 完成終端機互動，並以多個組合語言模組拆分主流程、姓名輸出及 ID 處理。

## 功能與流程

1. 顯示隊伍編號與三位組員姓名。
2. 依序輸入三位組員的整數 ID。
3. 輸入小寫 `p`，列出 ID 與總和。
4. 主程式整合顯示隊伍、各組員 ID／姓名與 ID 總和。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `main.s` | 程式入口，呼叫 `name`、`id`，並整合輸出成員資料 |
| `name.s` | `name` 函式，輸出隊伍與組員姓名 |
| `id.s` | `id` 函式，讀取三筆 ID、等待指令並計算總和；提供 `ids` 與 `idsum` 全域資料 |

## 編譯與執行

在具有 GCC 與 C 標準函式庫的 **32 位元 ARM Linux** 環境，從本資料夾執行：

```sh
gcc -o main main.s name.s id.s
./main
```

輸入範例（每行輸入後按 Enter）：

```text
1001
1002
1003
p
```

上述資料的 ID 總和為 `3006`。姓名與隊伍編號由程式中的字串定義。

## 實作重點

- 透過 `bl` 呼叫自訂函式與 C 標準函式庫。
- 使用記憶體配置保存三筆 ID 與總和。
- 使用條件分支、迴圈與位址遞增讀取資料。
- 使用堆疊保存與還原返回位址。
